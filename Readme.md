# Visual Anomaly Detection: Гибридная система промышленного контроля качества

Данный репозиторий содержит исходный код системы дефектоскопии, разработанной для автоматического анализа производственного брака на двух принципиально разных типах поверхностей: дискретных объектах со строгой геометрией (лесные орехи) и непрерывных высокочастотных текстурах (кожа).

Основной приоритет проекта — **отказ от использования готовых комплексных фреймворков** (таких как Anomalib) в пользу самостоятельного проектирования, сквозного обучения и математической калибровки архитектур под конкретные производственные задачи.

---

## 1. Архитектурный вызов: Объекты против Текстур

В процессе разработки была обнаружена фундаментальная проблема универсальных моделей: алгоритм, эффективный для локализации брака на штучных деталях, демонстрирует полное падение точности при анализе непрерывных текстур.

### Дилемма геометрических объектов

Для контроля лесных орехов важна трансляционная инвариантность и понимание глобальной структуры. Объект может быть слегка смещен или повернут в кадре. Сверточные автоэнкодеры со сжатием (Bottleneck) успешно справляются с этой задачей, выучивая компактное многообразие признаков нормального распределения.

> *«Сверточные сети подходят для обработки данных, имеющих сеточную топологию. Благодаря совместному использованию параметров и инвариантности к сдвигу, они способны эффективно восстанавливать обобщенную топологию объектов, игнорируя незначительные пространственные флуктуации».* > — **Ян Гудфеллоу, Йошуа Бенжио, Аарон Курвилль, «Глубокое обучение»**

### Дилемма высокочастотных текстур

При попытке применить автоэнкодер к текстуре кожи метрика ROC-AUC упала до критических **0.41**, что эквивалентно случайному угадыванию с инверсией классов.

Кожа обладает стохастической (хаотичной) микроструктурой пор и морщин. Использование классической функции потерь MSE заставляет автоэнкодер минимизировать среднеквадратичную ошибку путем генерации усредненного, сильно замыленного кадра. При вычитании оригинала из такой реконструкции вся здоровая поверхность начинает ложно определяться как аномалия.

## 2. Разделение подходов: Нейросети и Словари

Для преодоления координатного коллапса архитектура проекта была разделена на два независимых вычислительных конвейера:

### Конвейер А: Глубокая реконструкция (main.py)

Используется для объектов с выраженными пространственными границами (`hazelnut`). Включает в себя две архитектуры свёрточных автоэнкодеров: `ConvAutoencoder` (Base) и `LargeConvAutoencoder` (Large) с увеличенной емкостью фильтров. Модели обучаются минимизировать ошибку восстановления только на бездефектных образцах.

### Конвейер Б: Статистическое моделирование распределений (extended_main.py)

Используется для стохастических непрерывных поверхностей (`leather`). Метод реализует алгоритм **PaDiM (Patch Distribution Modeling)**.

Вместо обучения весов градиентным спуском, изображения пропускаются через замороженный экстрактор признаков ResNet-18. Для каждого пространственного патча вычисляется многомерное математическое ожидание $\mu$ и обратная матрица ковариации $\Sigma^{-1}$, формируя статистический «словарь нормы». На этапе инференса мерой аномалии выступает **Расстояние Махаланобиса**.

> *«Матрица ковариации позволяет учитывать не просто разброс значений отдельных признаков, а их взаимную зависимость. Расстояние Махаланобиса измеряет удаление точки от центра распределения в единицах стандартного отклонения, что делает его незаменимым для оценки аномалий в многомерных пространствах с выраженным шумом».* > — **Кристофер Бишоп, «Распознавание образов и машинное обучение»**

## 3. Анализ результатов тестирования (A/B/C Исследование)

Каждая модель прошла валидацию на тестовых выборках с вычислением метрики ROC-AUC. Результаты сведены в единую матрицу:

| Домен данных | Base (Сверточная сеть) | Expanded (Словарь PaDiM) | Large (Увеличенная емкость) |
| --- | --- | --- | --- |
| **Орехи (Hazelnut)** | 0.8307 | 0.7904 | **0.8761** |
| **Кожа (Leather)** | 0.4137 | **0.8658** | 0.4093 |
| **Микс (Смешанный)** | 0.6775 | 0.6357 | 0.6869 |

### Ключевые выводы бенчмарка:

1. **Превосходство емкости на геометрии:** Увеличение каналов автоэнкодера (`Large`) подняло точность на орехах до максимума (**0.8761**). Сеть смогла точнее выучить форму и текстуру скорлупы. Статистический словарь на орехах просел (**0.7904**) из-за чувствительности к малейшим смещениям объекта относительно сетки координат.
2. **Бесполезность масштабирования на текстурах:** Увеличение параметров автоэнкодера на коже не привело к росту метрик (0.4137 против 0.4093). Проблема заключалась не в нехватке весов, а в самом принципе попиксельного сравнения.
3. **Победа PaDiM на коже:** Переход к локальным статистическим словарям признаков позволил поднять точность локализации дефектов кожи более чем в два раза — до **0.8658**.
4. **Коллапс смешанного домена:** Попытка обучить универсальную модель (`mixed`) на обоих типах данных привела к усреднению результатов и снижению эффективности на обеих категориях. Специализированные конвейеры надежнее универсальных решений.

## 4. Развертывание и использование проекта

### Установка зависимостей

Проект изолирован от внешних тяжелых фреймворков и требует минимального набора библиотек. Установите их командой:

```bash
pip install -r requirements.txt

```

## Подготовка набора данных

В связи с ограничениями GitHub на максимальный размер загружаемых файлов, исходный набор данных `data.zip` (1.09 ГБ) не включен в данный репозиторий. Для корректной работы алгоритмов визуального обнаружения аномалий необходимо загрузить данные вручную.

**Инструкция по настройке:**

1. Скачайте архив `data.zip` из облачного хранилища по ссылке: [Google Диск](https://drive.google.com/file/d/1oGmMU37zama4by7tkkOx4tlHiGRP4dvZ/view?usp=drive_link).
2. Поместите скачанный архив в корневую директорию проекта.
3. Распакуйте содержимое архива. Убедитесь, что итоговая структура директорий соответствует путям, указанным в конфигурации скриптов (например, данные распакованы в папку `data/`).
4. (Опционально) Удалите исходный архив `data.zip` после распаковки для экономии дискового пространства.

*Примечание: Архив `data.zip` внесен в `.gitignore` во избежание повторных конфликтов при отправке коммитов.*

### Сквозное обучение и генерация артефактов

Для обучения нейросетей, их оптимизации и последующего экспорта в кроссплатформенный формат ONNX выполните:

```bash
python main.py

```

Для построения статистических словарей и расчета матриц ковариаций PaDiM выполните:

```bash
python extended_main.py

```

*Примечание: Оба скрипта автоматически формируют и дополняют файл `models/metrics.json`, который используется веб-интерфейсом.*

### Запуск аналитического веб-интерфейса

Для запуска интерактивного веб-сайта контроля качества (на базе Streamlit) выполните:

```bash
streamlit run app.py

```

Интерфейс автоматически сканирует директорию `models/`, предоставляет оператору выбор активной модели, выводит бинарный вердикт (Норма/Брак), строит пространственную тепловую карту дефектов и размечает область повреждения с помощью ограничивающей рамки (Bounding Box) на основе адаптивного локального порога ошибок.
